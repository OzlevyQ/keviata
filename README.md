# קביעותא — Keviata (static demo preview)

Public **demo preview** of the Keviata daily-study app (קביעותא), published as a
static GitHub Pages site for review purposes only.

- Static HTML/JS/CSS only. No backend, no accounts, no real user data.
- Authentication, progress sync and email subscriptions are stubbed with local
  mock data (localStorage); the original Netlify functions are not included.
- Daily edition content lives in `content/2026-09-17.json`.
- Image credits and licenses: see `images/CREDITS.md`.
